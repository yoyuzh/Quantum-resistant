# 抗量子密码风险检测与迁移辅助软件验证说明

## 常规检查

```sh
python -B -m unittest discover -s tests -v
npm --prefix web test
npm --prefix desktop test
npm --prefix web run build
python -B scripts/ci_smoke.py
```

先构建前端，再验证 FastAPI 页面。HTTP 冒烟启动独立本地服务，检查首页、JS/CSS、健康、配置和静态片段扫描，结束后停止服务。远程自动测试全部使用 mock；不执行输入代码、`sample_inputs/` 或其他风险样例。

Python 覆盖扫描规则、AST/配置/PEM、复杂度与截止、上传/归档、HTTP 安全、调度/取消、临时存储、热门快照、报告、桌面通信和发布身份。Node 原生测试覆盖前端纯函数、导航、关系图、请求与进度、主题和桌面策略，不以 Python 复制前端逻辑。

Windows 可设置 `PYTHONUTF8=1`，保证中文子进程输出与父进程解码一致。并行运行完整 Python 回归时分别设置 TMP/TEMP/TMPDIR，避免暂存清理相互影响。

## 离线界面验收

```sh
python -m tests.browser_fixture
```

仅访问 `http://127.0.0.1:8018/`。本地扫描、上传、导出和后台任务使用真实逻辑，远程采集使用模拟数据。仓库或包名控制以下场景：

- `timeout`、`failure`：超时或失败。
- `slow`：8 文件慢任务；`large`：120 文件慢任务。
- `unknown`：候选总数未知；`legacy`：缺少范围或分析字段的历史结构。
- `expired`：保留结果及代码证据，但按需读取源码返回模拟过期错误，可验证重试入口。
- 热门两个成功仓库及一个失败仓库；第二次刷新失败，第三次恢复。

`/fixture/report` 提供报告样例，`?kind=partial`、`zero`、`unknown` 检查不同状态。桌面 fixture 的独立环境变量和启动方式见 [桌面说明](desktop.md)；模拟逻辑不接入生产入口。

`/fixture/desktop` 仅预览网页在36px桌面标题栏下的布局，使用无权限的测试桥接；不模拟原生窗口按钮、系统缩放或 Electron IPC，也不作为安装包 GUI 验收。

检查四输入模式、刷新恢复、取消与部分结果、失败保留、同名文件身份、超过50条发现的分页、源码定位、证据往返、热门详情和四种导出。覆盖 1440×960、1280×720、390×844 明暗主题、键盘焦点、长路径和减少动画偏好。HTML 单独检查无脚本、完整证据和打印分页；JSON/CSV 核对原始发现与数据契约。

## V1.2.0 验证记录（2026-10-25）

本版将重复的阶段记录合并为当前验证范围；功能变更见 [更新记录](../CHANGELOG.md)，布局与数据边界见 [架构说明](architecture.md)。保留全部有效回归测试，不因文件名相近删除不同场景的测试。

发布前完整Python回归225项、前端71项、桌面11项测试、生产构建和真实FastAPI HTTP冒烟均通过。版本校验覆盖 API、网页、两个 npm 清单及锁文件。远程采集测试全部 mock，样例只作静态扫描。

已实测1280×720、1024×768和390×844的代表性页面：输入提交后收起、编辑输入与恢复、发现筛选及分页、资产分页、源码展开、证据关系图、迁移参考抽屉和明暗主题。390px无页面级横向溢出，详情抽屉Escape关闭后返回原行，筛选器支持键盘选择。

结果区与导航等宽衔接，正文桌面20px、窄屏16px留白。背景仅在适用区域保留点阵，发现明细左侧为纯色；分页、标题与页签不使用冗余灰色分隔线，相邻记录、控件及分栏保留必要边界。浏览器检查确认分页栏顶部、列表末项底部和抽屉页签的灰色边线均为0，控制台无错误或警告。

七文件静态样例生成15项发现，验证发现列表和资产清单真实翻页，发现行完整显示；图内搜索保持全量统计，输入展开/收起及切换子页保留已有结果。离线fixture另验证远程失败保留输入并提供重试。参考抽屉保持分类阅读位置、按需知识加载及关闭焦点返回，相关状态由Node回归覆盖。

## 桌面构建与交付

运行版本为V1.2.0，登记版本仍为V1.0.0。版本标签必须对应确切提交，四个平台通过同一提交的CI后原生构建，验证冻结后端、锁定运行依赖、安装包格式和SHA-256。Release的 `BUILD-INFO.json` 记录版本、提交及各平台身份，`SHA256SUMS.txt` 覆盖全部安装包。构建及发布结果以 [GitHub Actions](https://github.com/yoyuzh/Quantum-resistant/actions) 和 [Release](https://github.com/yoyuzh/Quantum-resistant/releases) 为准。

本机为Windows 11、Python 3.13.5、Node.js 24。Windows构建使用 `npm --prefix desktop run build`，包含前端和桌面测试、PyInstaller冻结、冻结后端离线冒烟、NSIS安装包和校验文件。四平台发布步骤见 [开发说明](development.md)，桌面数据目录、原生窗口与保存行为见 [桌面说明](desktop.md)。

## 未验证范围

系统减少动画/高对比度、实际200%浏览器缩放、触屏硬件、HTML实际打印分页、Windows拖动和不同DPI、macOS/Linux安装后GUI及旧版覆盖安装仍需实机复核。小视口检查不等于真实缩放或DPI验收；自动回归与冻结后端冒烟不能代替安装后GUI验证。

安装包未正式代码签名，macOS未Apple公证。GitHub仅支持公开仓库，匿名搜索受额度约束；网络和代理会影响实际采集，零发现或部分扫描不能证明安全。应用运行版本与软著登记版本分别维护，不据本次验证推断开发完成或首次发表日期。
