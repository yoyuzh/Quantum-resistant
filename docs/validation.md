## 自动覆盖范围

- 静态扫描：已知API、完整导入目标、遮蔽与重新赋值、JWT参数优先级、配置边界、PEM未知项、畸形语法回退、逐来源身份及资源上限。
- 跨文件：至少60组正例、负例和未知案例；独立实参、绝对与相对导入、参数和返回传播、缺模块、递归及不支持语义。AST缓存最多2文件，不执行输入。
- AI：四种协议的正常输出、拒答、空内容、截断、伪造或越权引用、缺项、限流、超时、恢复预算、取消和迟到；明确弃答与请求失败分别记账，不提高静态证据等级。
- 配置：多模型切换、提交时绑定、版本失效、跨模型续处理、空密钥保留、逐项删除、旧配置迁移和安全存储失败。网页密钥不进入浏览器存储，桌面通过safeStorage及私有stdio管理。
- 任务与存储：2运行/4排队、幂等、检查点、终态冻结、来源到期、读者保护、配额、原子替换失败及热门快照保护。
- 前端与桌面：真实结果字段、筛选、分页身份、长路径、图形几何和成员计数、渐变结束、取消恢复、IPC边界、下载来源、加密失败及进程关闭。

## 页面复查

```sh
python -B -m tests.browser_fixture
python -B -m tests.assisted_browser_fixture
```

两个入口只监听`localhost:8018`，远程采集和模型均模拟；不可同时占用同一端口。辅助fixture可设置`QUANTUM_FIXTURE_REAL_FILES=true`，只读扫描7个风险样例；`scale5000`输入生成5000份合成源码。正式入口不导入fixture。

历史页面实测覆盖1440×960、1280×720、390×844及明暗主题：首次与重新扫描统一等待，终态后呈现；配置缺失引导、静态降级、补做、停止、来源过期、刷新恢复、源码侧栏、资产抽屉、迁移方案、搜索与空图均有记录。手机允许自然纵向阅读，完整图在独立窗口内平移缩放。关闭窗口返回原入口，图例和工具换行后复位避开底部区域。

入口背景为装饰性雾化流程图，不冒充扫描数据。完整图只保留图形，列表和旧分页已移除；悬浮左线只联动自身及对应右侧，悬浮右线联动相应左侧。消息自动淡入淡出，不要求关闭；模型勾选项仅方框可点击，文字与空白不误选，键盘空格保留。扫描等待页顶部只显示来源及用时。

## 验证边界

历史实网消耗和性能见[AI历史实测](ai-validation.md)，不能将结构通过率当作准确率。没有独立人工金标准；除DeepSeek外的供应商尚未逐一实网验收。系统减少动画主要通过实现及纯函数检查，未完成所有系统偏好、触屏硬件或平台原生窗口组合测试。安装包尚未正式代码签名或Apple公证，自动构建不等于完整安装后GUI认证。

V1.3.0远程Linux检查暴露了桌面多模型测试模拟缺少安全后端接口的问题，已补齐并增加跨平台basic_text拒绝回归。该标签保留用于追溯，安装包改以V1.3.1发布，不改写已推送标签。
