# 抗量子密码风险检测与迁移辅助软件验证说明

## 常规检查

```sh
python -B -m unittest discover -s tests -v
npm --prefix web test
npm --prefix desktop test
npm --prefix web run build
python -B scripts/ci_smoke.py
```

先构建前端，再验证 FastAPI 页面。HTTP 冒烟启动独立本地服务，检查首页、JS/CSS、健康、配置和静态片段扫描，结束后停止服务。远程自动测试全部使用 mock；不执行输入代码、`sample_inputs/` 或其他风险样例。

Python 覆盖扫描规则、AST/配置/PEM、复杂度与截止、上传/归档、HTTP 安全、调度/取消、临时存储、热门快照、报告、桌面通信和发布身份。Node 原生测试覆盖前端纯函数、导航、关系图、请求与进度、主题和桌面策略，不以 Python 复制前端逻辑。

Windows 可设置 `PYTHONUTF8=1`，保证中文子进程输出与父进程解码一致。并行运行完整 Python 回归时分别设置 TMP/TEMP/TMPDIR，避免暂存清理相互影响。

## 离线界面验收

```sh
python -m tests.browser_fixture
```

仅访问 `http://127.0.0.1:8018/`。本地扫描、上传、导出和后台任务使用真实逻辑，远程采集使用模拟数据。仓库或包名控制以下场景：

- `timeout`、`failure`：超时或失败。
- `slow`：8 文件慢任务；`large`：120 文件慢任务。
- `unknown`：候选总数未知；`legacy`：缺少范围或分析字段的历史结构。
- 热门两个成功仓库及一个失败仓库；第二次刷新失败，第三次恢复。

`/fixture/report` 提供报告样例，`?kind=partial`、`zero`、`unknown` 检查不同状态。桌面 fixture 的独立环境变量和启动方式见 [桌面说明](desktop.md)；模拟逻辑不接入生产入口。

检查四输入模式、刷新恢复、取消与部分结果、失败保留、同名文件身份、超过50条发现的分页、源码定位、证据往返、热门详情和四种导出。覆盖 1440×960、1280×720、390×844 明暗主题、键盘焦点、长路径和减少动画偏好。HTML 单独检查无脚本、完整证据和打印分页；JSON/CSV 核对原始发现与数据契约。

## V1.1.1 验证记录

本版本合并此前阶段记录，变更内容统一见 [更新记录](../CHANGELOG.md)，实现边界见 [架构说明](architecture.md)。保留全部有独立覆盖价值的测试及公共兼容导出，清理未使用导入、重复构建目录和生成缓存。

发布前本机完整 Python 回归225项、前端52项、桌面11项全部通过。前端生产构建、真实 FastAPI HTTP 冒烟、Windows 冻结后端与 NSIS 安装包构建通过；安装包版本1.1.1、格式与 SHA-256 核对通过，未正式代码签名。旧生成目录移出项目并保留临时备份。

Windows 11 使用独立开发实例实测：菜单入口已移除，F10 不弹出菜单；明暗主题下原生按钮悬停区域为紧凑横向矩形，检查最大化、恢复、最小化、标题栏双击、Ctrl+R 重载保持主题及关闭退出。启动窗口与主窗口、主题切换后的覆盖高度均由自动回归核对为36px。拖动注入未确认窗口位移，保留手工复核；没有把开发实例验收表述为安装/覆盖升级验收。

自动回归包括共享迁移流程与专属说明、JSON/CSV 不变性、导航返回/分页/快速连续操作、同名文件与关系路径、主题初始化和 IPC 边界。GitHub 覆盖遗留令牌不再使用、请求不发送 Authorization、匿名 401/403/429、公开归档中的源码和 Markdown、main/master 回退和热门查询。版本检查核对网页、API、两个 npm 清单及锁文件；冻结后端携带版本清单。

此前离线浏览器验收通过四类输入、零发现、历史结构、55条发现分页、资产往返、热门详情与完整扫描预填，以及上述三种尺寸的明暗主题。实际导出确认 HTML/Markdown 通用流程与标准链接只出现一次，JSON 和 CSV 保留完整发现。选择栏无外层底框，展开入口使用文字与箭头；390px 无横向溢出，触屏控件至少44px。连线提示通过真实指针进入事件和 Node 状态回归验证，未连续移动验收跨线切换。

此前本机联网诊断确认失效凭据与长限流等待、PyPI 直连优先是慢请求的原因之一。当前统一匿名访问，限流退避最多2秒；仓库尝试公开归档，热门检索仍依赖搜索额度。PyPI 使用配置的代理，仅自动系统代理连接故障可直连回退。历史网络耗时不作为稳定速度保证，自动回归不访问真实远程服务。

## 桌面构建与交付

版本标签必须对应确切提交，四个平台复用 CI 后原生构建，验证冻结后端、安装包格式和 SHA-256。Release 的 `BUILD-INFO.json` 记录版本、提交及各平台身份；`SHA256SUMS.txt` 覆盖全部安装包。流程与使用方法见 [开发说明](development.md) 和 [桌面说明](desktop.md)。

本机环境：Windows 11、Python 3.13.5、Node.js 24.15.0。已有 Windows 安装验收曾覆盖静态扫描、证据定位、原生报告保存及退出回收；本版标题栏的实际检查范围见上文。

## 未验证范围

系统减少动画、高对比度、触屏硬件、源码过期界面、HTML 实际打印分页、Windows 手动拖动与不同 DPI、macOS/Linux 安装后 GUI 及旧版覆盖安装仍需实机验收。安装包未正式代码签名，macOS 未 Apple 公证。自动检查或托管构建不等于这些项目已通过。

GitHub 只支持公开仓库，匿名搜索受额度约束；网络和代理会影响真实采集，零发现或部分扫描均不能证明安全。应用版本与软著登记版本分别维护，不据本次环境推断开发完成或首次发表日期。
