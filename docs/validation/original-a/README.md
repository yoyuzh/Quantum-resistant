# 原版 A 接入验证证据

这些记录来自接入阶段的本地运行，基线和命令见 [接入说明](../../original-a-engine.md)。PR 创建前逐文件校验，本轮源码及构建产物与已验证版本一致；此处记录不代表当前远端 CI 状态。

- `comparison.json`：三版本固定语料指标、完整 A 输出一致性检查和声明式支持矩阵。
- `cases.json`：36 例固定语料及15例开发兼容集的逐例指标与覆盖；没有按预测修改标签。
- `support-comparison.json`：开发兼容集汇总，保留 EC/ECC 字段标注差异。
- `resources/`：小输入、A 边界、越界、5000文件及取消的独立子进程实测。
- `http.json`：真实本地 HTTP、Origin、源码定位及四报告证据。
- `validation.txt`：本地测试、构建与 stdio 冒烟的命令和原始输出末尾。

完整逐例原始结果、证明与浏览器截图保留在本地 `output/`，没有将会话缓存、浏览器配置或其他用户材料纳入提交。完整原始对照可运行 `python -B scripts/compare_original_a.py` 生成。模型网络为 mock；独立留出集、真实模型准确率及跨平台实机仍未验收。

来源完整性测试需要固定 A 提交的 Git 对象。CI 使用完整历史检出；本地浅克隆应先获取对应历史，再运行比较与契约测试，测试本身不自动触发远程访问。
