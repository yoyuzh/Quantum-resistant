# AI 辅助分析

扫描按钮旁的“AI 辅助”开关首次默认开启，并记住选择。开关只影响下一次扫描；关闭后仍执行逐文件规则和 Python 跨文件静态分析。勾选AI但没有可用配置时，网页提供“去配置”“仅静态扫描”“取消”。保存并启用可用配置后自动继续原扫描；仅静态扫描只影响本次，不改变开关偏好。旧API客户端仍可在未配置模型时完成静态扫描。

## 配置模型

“模型设置”可保存最多32份配置，并单独选择一个启用项，也可全部停用。先选择服务、地区与协议，填写供应商提供的API模型ID和密钥，确认发送必要脱敏片段后保存。第一份配置使用“保存并启用”；之后新增和保存不自动切换启用项。开关旁直接显示当前模型和状态，启动时只读取保存状态，不自动调用服务验证。

预设覆盖OpenAI、Azure OpenAI、Claude、Gemini、DeepSeek、阿里云百炼、智谱、Kimi、MiniMax、火山方舟、百度千帆、腾讯混元／TokenHub、SiliconFlow、OpenRouter、xAI、Mistral、Groq、Ollama、LM Studio和自定义服务。阿里云须明确选择地区；Azure须填写实际资源地址和部署名称。ChatGPT网页订阅不能作为API凭据。预设不保证任意模型都支持相同参数，模型ID及输出能力应以供应商为准。

支持OpenAI Chat Completions、OpenAI Responses、Anthropic Messages和Gemini GenerateContent四种协议，统一校验返回结构、证据和语义。原生JSON Schema、JSON对象及提示约束JSON由配置显式选择；不会在失败后轮流尝试参数或协议。DeepSeek默认关闭思考并使用JSON输出；本机服务可明确选择无鉴权。HTTP仅允许回环地址，外部端点须HTTPS，禁止重定向。

“测试连接”只向选中配置发送固定短文本，不发送源码，也不要求先授权源码发送。连接测试和启用操作相互独立。保存与测试结果以居中消息自动淡入淡出，不撑开设置窗口，也不需要手动关闭；失败时保留编辑内容。界面区分配置完整、未授权、未测试、最近成功、鉴权失败、余额不足和凭据未恢复；已知鉴权或余额错误会引导重新配置。临时网络故障沿用有界恢复，不自动改用备用模型。

网页默认记住配置：密钥保存到受信系统keyring，非秘密元数据原子保存到用户数据目录。桌面由主进程通过safeStorage加密，并用私有stdio交给后端；不通过网页HTTP写入桌面凭据。安全存储不可用或保存失败时仅用于当前进程，界面显示“仅本次运行”，不降级为明文文件。空密钥保留原值；更换地址不继承原密钥。取消记住、删除凭据及删除配置分别处理，配置与扫描15分钟保留期无关。[keyring说明](https://keyring.readthedocs.io/en/latest/)。

旧单配置在安全保存新格式后迁移，失败时保留原存储。环境变量配置作为只读项显示：`QUANTUM_AI_ENABLED=true`、`QUANTUM_AI_BASE_URL`、`QUANTUM_AI_MODEL`、`QUANTUM_AI_API_KEY`、`QUANTUM_AI_CONSENT=true`。首次沿用旧优先级；后续明确保存的启用选择优先，也包括全部停用。密钥不进入浏览器存储、任务、报告或日志。配置写入和连接测试仅允许本机管理访问。

任务在提交时绑定配置ID和版本；排队和静态阶段切换启用项不会改变当前任务。修改所绑定配置的地址、凭据或发送授权，以及删除该配置，会停止其未发送批次；其他配置的编辑不影响它。更换地址或协议须重新确认发送，保存无实际变化的内容不打断任务。

新增接口：GET `/api/ai/providers`；GET／POST `/api/ai/profiles`；PUT／DELETE `/api/ai/profiles/{id}`；PUT `/api/ai/active`（`profile_id:null`全部停用）；POST `/api/ai/profiles/{id}/test`；DELETE `/api/ai/profiles/{id}/credential`。原`/api/ai/config`和连接测试映射当前配置，继续兼容。扫描和补做可显式提交`ai_profile_id`、`ai_profile_version`；过时选择返回409，防止静默发往其他模型。

## 扫描与二次分析

首次扫描和重新扫描采用相同等待页面，依次显示采集、规则分析、跨文件核验、模型复核和结果整理。已知分母时显示当前步骤的实际完成量和百分比，未知时使用不定进度。等待页同步显示当前文件、检索或核验动作、剩余问题组和本批响应等待时间，并保留最近两条不同的任务动态；总用时与本批等待合为一行，历史动态不再重复显示时间；不根据等待时长编造完成百分比。后台仍保存检查点，网页在任务结束、部分完成、停止或失败后统一展示可用结果；失败且没有本次结果时恢复上次结果并标注。未配置模型时完成静态分析，不无限等待。

同一浏览器会话记住最近使用的输入来源和任务ID，刷新后读取服务器已有结果，不重复提交。浏览器不保存源码或密钥；输入草稿不会恢复，重新扫描前需确认输入。

关闭 AI 完成扫描后，点击“补做 AI 分析”复用保留的源码、模块摘要和候选，不重新采集或重跑规则。预算尚有未处理问题时可继续；存在可重试项时提供重试入口。问题全部处理后不显示重试，语法或覆盖诊断单独保留。恢复项优先于新一轮问题，成功意见不重发。已完成的有效意见可以复用。普通跨扫描缓存仍绑定模型及配置版本。用户明确更换模型继续同一来源时，只保留快照、规则、提示、策略和结果协议均兼容的有效意见，分析剩余项；每条意见保留`model_origin`，每次运行在`runs`中记录模型、调用及用量。

“停止 AI”停止后续请求并丢弃停止后到达的响应，保留基础结果和已接纳的完整意见；已发送数据无法撤回。源码和结果沿用终态15分钟、最多8份及容量限制，空间压力也可能提前回收。来源不可用时明确提示，不自动重新下载。需长期保存的结果请及时导出。

发现明细、概览、资产、证据关系图和迁移待办共用服务器整合结果，不再设置独立的辅助分析页。程序独立核验的跨文件风险进入确认统计；证据充分且没有关键缺口或静态冲突的模型结论自动采纳为“AI研判”，与“静态确认”“证据不足”在同一列表分别标记；评分只按静态确认计算。模型判断不会获得静态证据等级。详情保留用途、模型意见、缺失信息和证据；关系图可切换“迁移关系”与“调用与证据”。两种入口使用同一雾化流程背景，点击中央“打开完整图”查看实际数据。完整窗口支持全屏、搜索、筛选、平移缩放、小地图和当前视图SVG导出，没有分页或列表模式；右下角图例解释节点与线型。滚轮缩放、拖动平移，复位居中显示全部。悬浮左侧连线只突出自身及对应右侧，悬浮右侧才同时突出对应左侧；显隐使用短暂渐变。完整记录仍可搜索，低倍聚合不删除数据。静态确认、AI研判和证据不足使用不同线型；只有定义位置时显示证据卡片，不虚构调用链。用途未经确认时先核对用途，再决定迁移方向。

网页通过 `GET /api/tasks/{id}/report/{format}` 导出服务器保存的 HTML、Markdown、JSON、CSV，包含融合发现与状态，不附完整源码。HTML 和 Markdown 另列资产、调用关系和迁移待办。原报告接口及原 `findings`、`summary`、`analysis` 基础语义保持兼容；`integrated_analysis`版本3增加`effective_purpose_code`、`purpose_origin`和`migration_references`，统一网页与报告的用途呈现；历史结果回退原结构。静态用途未知时可采用有效AI用途并标注来源，不因此提高静态评分。AI结果版本`ai-assisted-5`的`execution`记录完成、剩余、重试和失败分类，`coverage.search_partial`单独记录检索覆盖限制。

资产卡片通过“查看详情”打开右侧抽屉，不撑开同一行。抽屉可切换当前页资产、查看完整API和证据位置；点击证据后定位发现明细。用途未知时，迁移图和卡片展示带适用条件的家族参考，不表示可以直接替换API。概览中的文件矩形树图可定位文件发现，面积表示记录数量。最新真实输入、恢复及界面验收见[验证记录](ai-validation.md)。

## 热门批次

热门榜单使用同一AI开关。点击扫描后隐藏旧榜单并显示统一等待页，终态后展示本次结果；失败时不回显旧榜单。网页不自动加载磁盘快照，刷新只恢复仍在运行的任务，服务重启或任务过期后显示初始页。

仓库的源码、包根、索引、候选和证据分别保存，同名模块不会跨仓库解析。候选按仓库轮询，整批共享900秒、384次调用和32 MiB请求预算；基础及跨文件阶段合计1200秒，总截止2100秒。沿用原采集和临时存储上限，批次合并候选最多20000组，超出时公开未覆盖范围。只有整批完整结束才原子更新兼容快照；停止、部分失败和写入失败均保留上一完整快照。

榜单携带摘要，选中仓库后通过GET /api/tasks/{id}/repositories/{repository_id}读取完整融合结果，按source_id读取源码。导出同一仓库报告使用GET /api/tasks/{id}/report/{format}?repository_id=...。详情中的调用数与token标为整批共享，避免误认为每仓库单独消耗。

## 分析范围和可信度

基础规则与跨文件分析共用导入 API 和 JWT 算法标识目录，并记录规则版本。跨文件核验覆盖 cryptography、PyCryptodome、PyJWT 的已声明子集，以及 python-ecdsa 默认曲线和受信导入的NIST、SECP256k1及已列入规则的Brainpool曲线的生成、签名和验签。EdDSA、动态或被遮蔽的曲线不按ECDSA确认；额外的可选签名参数、不支持的导入和方法继续保留未知。RSA 公钥加密、私钥解密和 EC 密钥建立分别检查接收者类型，不凭方法名猜测用途。

Python 支持唯一包根下的绝对／相对导入、别名、模块常量、顺序赋值、普通及关键字参数、静态默认值、透明返回和有限条件分支。目录上传会保存相对路径；同名模块、平铺上传或包根歧义不强行拼接。动态导入、反射、复杂控制流和超限传播保留未知。静态调用及算法策略不证明实际运行或部署；JWT 解码的允许算法列表也不证明令牌实际采用的算法。

AI 从未解析密码用法、独立密码线索和已有发现复核三路选取问题，份额为50%／25%／25%，空余额重分配。上下文包含必要的调用方、封装、配置和导入；允许一轮在已采集范围内补充定义。模型只能返回限定字段和证据 ID，服务器检查结构、引用和快照。引用有效只表示证据存在，不能证明模型的语义判断正确。

其他受支持的代码语言通过词法过滤提取未知密码封装线索，跳过注释和普通字符串，进入 AI 分析候选；这不构成跨文件语义证明。完整的多语言解析仍未实现。

通用 PEM 头不推断 RSA；算法名称不直接证明用途。算法和用途按字段研判：缺少用途不抹去已有算法判断。只有存在冲突或需要补充必要信息时才要求用户处理；普通数学运算、不透明函数名和恶意注释不能作为确认依据。迁移待办依据已知用途和版本化本地知识生成，并标明静态或AI来源，不证明库支持、协议兼容或迁移完成。软件不执行输入代码、不安装被扫描依赖，也不提供自动改写或真实供应链传播证明。

## 默认预算

| 项目 | 上限 |
|---|---:|
| 本地检索 | 5000文件／100 MiB文本 |
| 单文件 | 2 MiB；AST 50000节点／深度64 |
| 跨文件阶段 | 180秒，受普通扫描剩余截止约束 |
| 传播 | 调用深度5／每函数64上下文／单切片400节点 |
| 静态结构 | 200万节点／400万边／256 MiB等价序列化结构 |
| AST缓存 | 2个文件 |
| AI选取窗口 | 每次最多1024组，处理完自动取得下一窗口 |
| 每次AI任务 | 384次调用／900秒，所有窗口共用预算 |
| 单次请求 | 128 KiB输入／常规最多12组，补救最多4组／8192输出token／45秒 |
| 每轮累计输入 | 32 MiB，重复发送也计入 |
| 单次响应 | 512 KiB |
| 模型HTTP并发 | 全局2 |

结构预算不是进程内存硬上限。基础阶段保留600秒截止；自动 AI 单独最多900秒，整次任务另受提交后1500秒总截止约束。独立补做和继续分析从提交时计900秒，包含排队和准备。问题按最多12组准备，两路请求每次常规最多12组，补救最多4组，完成后保存并释放代码上下文，再处理下一批；不是一次向模型发送所有文件。超过限制保留完整部分并记录未完成原因。没有完整处理的候选不会被伪装成弃答或零风险。

每组最多发送3次，包含首次请求、补充检索、结构补救和故障恢复，全部共用原任务预算。结构缺项只重发缺项；字段之间相互矛盾的输出不会被直接采纳。截断后缩小批次，成功项不重发。第三次发送隔离为单问题请求，防止反复引用其他问题的证据；校验原因明确到字段和约束，仍不放宽证据归属。连接中断、超时、429和可恢复的5xx自动恢复；默认等待1秒、3秒，服务提供Retry-After时优先遵守，等待超过剩余预算时停止。鉴权、余额和参数错误直接说明原因，不循环请求。连续3次结构补救无有效输出后停止后续请求；单组先达到发送上限时保留未完成原因。明确弃答、非密码操作和信息不足均作为已处理结果，不反复计入请求失败。提示、策略或快照不兼容时不复用旧意见；跨模型继续采用前述显式兼容规则。实际token按供应商返回值计量，无法完整计量时显示未知，不推算费用。脱敏不能保证识别所有秘密，首次授权前应确认代码允许发往所选服务。

每组3次发送是恢复上限，不代表每组固定调用3次。已完成的静态判断优先本地解释，相同证据去重发送；定义处保留已知API和算法事实，但不推断实际调用或部署。

## 验证入口

`python -B -m unittest tests.test_ai_integrated -v` 使用真实任务、存储和路由以及进程内模拟模型，覆盖补做、缓存、取消、限流、错误输出、预算和来源边界。

`python -B scripts/benchmark_assisted.py` 静态分析5000文件、100 MiB合成语料，记录时间、进程峰值内存、临时存储和AST缓存。结果位于 `tmp/assisted-validation/scale.json`；不执行生成的源码，不调用模型，也不能据此计算真实仓库准确率。

`python -B -m tests.assisted_browser_fixture` 在 `127.0.0.1:8018` 提供离线网页验收，GitHub、PyPI和模型均模拟。fixture只由此入口启用，不接入生产配置。

已完成授权的 DeepSeek 合成样例调试，调用上限8次，测试实例不覆盖用户配置，也未发送本项目源码。初期结构错误及最终结果见 [验证记录](validation.md)。这不是生产项目准确率或费用基准；多文件测试标签由代码审查制定，未经过独立人工金标准裁决。

历史授权实网测试、实际调用消耗和未验证边界统一见[AI实测记录](ai-validation.md)。一次性供应商诊断脚本已移除；日常回归和页面验收使用上述离线入口，避免意外读取凭据或重复消费。
