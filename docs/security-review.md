## 按严重程度整理的修复

| 优先级 | 问题 | 修复与回归 |
| --- | --- | --- |
| 高 | 整个web目录静态公开，可能读取源码、测试及依赖文件 | 仅挂载构建assets，显式保留入口与热门JSON；源码等404，统一nosniff及DENY响应头 |
| 高 | 浏览器跨来源提交及不可信Host | Host明确允许列表；写请求Origin同源或显式开发来源，拒绝null及重复头；无Origin保留CLI兼容 |
| 高 | 自动重定向未验证目的地、可能转发凭据 | 统一下载层每跳检查HTTPS/443/固定域名，最多5跳，跨源删除认证与Cookie；mock验证非法目标不连接 |
| 高 | HTTP解压与归档元数据/跳过成员开销未完整限制 | 有界解压；ZIP打开前核验真实中央目录成员与大小，TAR流式遍历；成员、元数据和累计展开预算包含不支持后缀 |
| 高 | 开发依赖有已知漏洞 | Vite升级6.4.3，保留兼容Vue插件，更新传递依赖及锁文件；官方npm registry审计0项告警 |
| 中 | JSON解析前缺少实际字节上限 | ASGI请求边界逐块计数并用单一有界缓冲，覆盖缺失Content-Length、多字节源码与报告限制 |
| 中 | 同步扫描绕过后台容量；上传读取前未预留容量 | 共用调度器2执行/4等待；上传先预留，断连、解析失败、重复提交及关闭释放容量；混合限流回归 |
| 中 | 相似multipart边界前缀可能截断正文 | 流式与兼容解析共用状态机，只接受完整合法分隔符；覆盖跨块、重复/超长头、截断与边界前缀 |
| 中 | 慢上传和断连可能长时间占用资源 | 600秒总时限、30秒空闲时限，408；断连清理已写入文件并释放名额 |
| 中 | 短写/异常导致偏移与容量错误，提交失败残留目录 | 成功后提交记账；失败回滚，回滚失败禁用文件并保守记账；关闭等待读者及摄取预留释放 |
| 低 | 路由、收尾和错误处理重复 | 提取执行服务、扫描/报告路由、请求边界、归档/HTTP安全模块；合并源码恢复，移除无引用封装/常量 |
| 低 | HTTP内网UUID兼容性及选中语义 | 安全随机数UUID回退、共享Fetch/XHR错误解析与取消清理；aria-selected对应实际选项 |

## 验证

- Python完整unittest：182项（包含新增安全、调度、短写、关闭读者和断连回归）。远程全部mock，输入仅作静态扫描。
- Node原生测试：34项；前端生产构建：Vite6.4.3成功。
- `npm audit --registry=https://registry.npmjs.org`：0项已知漏洞（当前锁文件，包含开发依赖）。
- FastAPI实际启动检查构建入口、assets、配置、拒绝静态源码及Host/Origin边界。
- localhost:8018离线fixture：代码片段、上传7份文本样例、GitHub与PyPI、刷新恢复、取消后部分结果、按source_id展开源码、导出生成状态、窄屏和键盘操作。
- 报告接口回归覆盖JSON/CSV/Markdown/HTML与转义。内嵌浏览器显示JSON“已生成/再次下载”，下载事件等待超时，因此未声称已验证浏览器下载落盘。
- App.vue为124行，最长业务组件271行，满足250/350行约束。

## 剩余限制

Host/Origin校验不能替代用户身份认证；无Origin客户端可调用服务，使用场景仍限本机和可信内网。仅单进程调度与互斥，不增加数据库、分布式协调或跨用户隔离。取消/超时仍协作式，不能强制中断单次Python分析。归档预算是资源边界而非操作系统级内存/CPU隔离；达到预算前没有完成分析的文件无法产生部分结果。固定远程域名不支持任意镜像，XZ TAR明确拒绝。

本次依赖审计覆盖npm锁文件，未实施Python依赖漏洞数据库审计。运行配置与限额见README；构建产物由npm构建生成。

参考：[Vite Windows路径绕过公告（修复版本6.4.3）](https://github.com/vitejs/vite/security/advisories/GHSA-fx2h-pf6j-xcff)、[randomUUID安全上下文要求](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID)。
