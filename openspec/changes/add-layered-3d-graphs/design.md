## Context

全景图由仓库分类模型与检出聚合生成，连线按 ID 打开摘要或任务证据。单仓由 Web Worker 生成节点和关系，节点用于打开源码面板。

## Decisions

- 使用同一个 3D 组件及场景生命周期。全景的数据适配维持现有线宽刻度，工作台按 Worker 的纵向顺序铺到二维网格，保持节点和边标识。
- 透视巡航使用 Z 轴平行切面。正视使用正交投影并横向拉开切面。逐层视图正对所选一层。远景隐藏次要标签，并限制大量工作台连线的绘制预算。搜索和证据依然使用完整布局数据。
- HTTP 和文件格式保持现有契约。内置仓库使用资料库摘要位置，有活动任务时才可读取已有源码，迁移和证据面板作为 HUD 保留。
- 使用节点实例批处理、分状态管道和可暂停的动效。WebGL 初始化或上下文失败时显示现有兼容画布。导出 PNG 合成当前画面与可见标签。
