# Spec Delta

## Purpose

把确定性深度分析作为显式可选阶段接入现有任务资源和保留机制，在取消、超时、来源丢失或存储失败时仍保留完整基础结果与已核验证据，不引入模型审批会话或额外无界执行池。

## ADDED Requirements

### Requirement: 显式模式与默认兼容

四类后台扫描 SHALL 接受analysis_mode=basic|deep，默认basic，非法422；deep先保存基础结果再运行，basic不输出deep_analysis或改变原字段。深度使用独立可选结果，不修改旧URL、CLI、同步行为、评分和报告结构。热门批次不自动deep。

#### Scenario: W-01 旧客户端与无Python
- **WHEN** 旧客户端不传模式，或显式deep输入无Python
- **THEN** 前者保持旧扫描；后者保留基础结果并标记deep skipped及原因

### Requirement: 结果后显式复用来源

系统 SHALL 提供 POST /api/tasks/deep-analysis，使用已结束source_task_id及X-Request-ID，新任务复用保存的基础结果/源码，不重新采集或重扫；共享队列、状态/结果/取消入口。同标识同输入幂等，输入冲突409、容量不足429、来源不存在404、已知不可读409。入队后开始前 SHALL 重验来源，不无限延长旧TTL。

#### Scenario: W-02 排队期间源被回收
- **WHEN** 深度任务等待执行时原源码到期
- **THEN** 记录来源缺失并保留可用基础结果，不联网补抓，不假装零风险完成

### Requirement: 共享预算与有界退出

系统 SHALL 保持2运行/4排队、CPU2、HTTP8和存储2GiB；普通总600秒，深度最多120秒且不超过剩余普通截止，来源后新深度任务最多120秒。初值200 Python文件/8MiB，单文件2MiB，AST50000节点/深度64，索引100000节点/200000边/32MiB等价结构，证据和结果共享有界计量，配置只下调。队列/CPU等待及实际分析时钟 SHALL 公开，不重置总预算；结构体积不冒充RSS硬保证。

第三方工具 SHALL 可合作退出或在有界子进程中终止并完成回收，不能以超时遗留后台计算或绕过配额。所有物化副本及索引计临时额度。

#### Scenario: W-03 深度预算耗尽
- **WHEN** 基础已耗去590秒或深度达到节点/时间/空间上限
- **THEN** 深度不获得额外600秒，仅保留完整已核验部分和具体截断原因，资源回收后结束

### Requirement: 部分结果与终态一致

系统 SHALL 原子保留基础结果和完整深度证据，半成路径不可作证明。内层状态completed/partial/failed/cancelled/skipped与外层旧任务枚举分开，深度失败/取消已有基础结果时外层partial。completed不意味着无Unknown或安全。取消成功后不得再启动新的深度工作，迟到回调不得改终态；写失败保留上一有效结果。

#### Scenario: W-04 取消或写失败
- **WHEN** 基础已完成后取消、证据写入失败或第三方迟到返回
- **THEN** 基础及已提交完整证据可读，半成证据丢弃，迟到结果不复活任务

### Requirement: 统一保留清理

系统 SHALL 共用终态900秒/8份/512MiB与全局2GiB，不为深度开无限缓存。仅实际读取期间使用来源保护，副本/索引/读者/进程/票据在结束/失败/取消时收尾；重启清理孤立目录且不自动续跑或外发。时间戳北京时间ISO+08:00，截止使用单调钟。

#### Scenario: W-05 重启与暂存不足
- **WHEN** 服务重启或临时存储满
- **THEN** 受控失败或保留完整旧结果，清理孤立资源，不继续失效任务或删除仍有读者的来源
