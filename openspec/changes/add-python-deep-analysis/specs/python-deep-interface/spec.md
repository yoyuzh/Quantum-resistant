# Spec Delta

## Purpose

为用户提供无需模型即可操作的同级深度分析视图，清晰区分基础结果与调用上下文证据，展示范围和未知原因，并通过准确源码跳转及有界独立导出支持复核与分享分析结果。

## ADDED Requirements

### Requirement: 同级入口和显式启动

系统 SHALL 提供同级“深度分析”入口；有可复用AI页签时调整该入口，当前无则新增，不重复增加两个同义入口或硬编码页签序号。打开只查看状态，显式启动才分析，不依赖模型配置，不改变四输入导航/快速结果/旧加载展示。平铺、片段、无源码及无Python SHALL 分别说明。

#### Scenario: U-01 查看而不启动
- **WHEN** 用户打开深度页签但未选择启动
- **THEN** 无分析任务或模型请求，原结果仍可查看，来源限制可见

### Requirement: 上下文和证据展示

页面 SHALL 展示算法、操作类型、风险类别、解析状态、逐项等级、调用点/底层位置、上下文、证据边/条件及未知原因。不同上下文可折叠但不能合并，未实例化模板单列；源码按source_id和精确位置定位，同名文件不混淆。等级/未知不能仅靠颜色表达。

#### Scenario: U-02 RS256与HS256
- **WHEN** 一个底层调用存在两种实参上下文
- **THEN** 可独立查看两条操作与各自路径，未知或冲突不隐藏在折叠摘要中

### Requirement: 覆盖进度和来源恢复

页面 SHALL 分开显示采集、可用、选中、解析、分析数量及各自分母，未知为未知而非100%；显示排队/分析、预算/截断、取消/超时/失败/来源过期和已保留结果。刷新仅恢复task/source ID，切换来源后迟到响应不覆盖新结果；默认不持久保存源码。

#### Scenario: U-03 部分结果与刷新
- **WHEN** 来源切换、页面刷新或深度被取消
- **THEN** 恢复正确来源的可用结果及缺口，旧异步响应不污染当前页，基础结果不清空

### Requirement: 独立白名单导出

系统 SHALL 通过 GET /api/tasks/{id}/deep-analysis/export 从服务端保存结果生成schema_version=deep-static-1 JSON，含快照/版本/操作/有限证据/覆盖/诊断/预算，不含完整源码、密钥/口令或宿主绝对路径。不接受客户端自报已核验状态，旧四类报告结构不变；格式合法不等于资产识别正确。

#### Scenario: U-04 不可用源码的导出
- **WHEN** 源码已过期但完整深度结果仍在保留期
- **THEN** 导出保存证据与当前可重放状态，不附已回收源码或伪造复验成功

### Requirement: 可访问与响应式

页面 SHALL 在1440×960、1280×720、390×844及明暗主题可用，支持键盘页签/焦点恢复、状态文字播报、减少动画和长路径折行。筛选/分页需保留不同操作上下文与匹配数，窄屏证据采用可读纵向布局。

#### Scenario: U-05 窄屏键盘复核
- **WHEN** 用户用键盘在390×844打开证据并返回
- **THEN** 操作可达、内容不横向溢出、焦点返回触发点且状态可用文字理解
