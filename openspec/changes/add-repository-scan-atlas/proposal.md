# Proposal

## Why

热门仓库页能比较各仓库的发现总量，但要逐个打开详情才能判断某种算法涉及哪些仓库。批次评审还需要一份能离线阅读和交接的清单，保留图中数字对应的样本范围、判断来源和证据位置。

## What Changes

- 在热门页增加「多仓库密码算法全景图」。复用系统证据图的节点画布，连接仓库与实际检出的算法，点选关系可进入对应的用途和证据。
- 新批次从完整仓库结果形成汇总，按算法、用途和判断来源计数。历史快照按已有字段展示基础检出情况。
- 增加「导出批次清单」操作，生成 UTF-8 Markdown 文档，包含批次范围、算法覆盖、逐仓结果、代表证据和失败原因。文档使用当前批次的完整范围。
- 新安装首次打开仓库全景时直接展示软件内置的 30 个公开仓库的真实扫描摘要。每个内置仓库附扫描时间、提交 SHA、规则版本和覆盖范围。
- 从热门批次收录或指定 1–30 个公开仓库继续扫描，自动保存新增结果。资料库以仓库全名去重，可导出和导入版本化 JSON，在另一台设备继续积累。

## Capabilities

### New Capabilities

- `repository-scan-atlas` 提供同批仓库的可比汇总、交互全景图和证据下钻。
- `repository-scan-inventory` 生成可独立阅读、与全景图可核对的批次清单。

### Modified Capabilities

## Impact

涉及热门批扫的仓库摘要、快照投影和热门页展示。对批次结果增补可选字段，沿用单仓库详情、现有证据视图和结果保存策略。文档由浏览器使用已取得的批次摘要生成。
