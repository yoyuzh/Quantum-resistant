# Spec Delta

## MODIFIED Requirements

### Requirement: 有界模型调用
系统 SHALL 限制每任务文件数、聚合后候选数、输入字节数、调用次数、单次响应字节数、输出 token 上限、单请求与总截止时间以及全局模型并发。批处理策略 SHALL 同时考虑输入字节、输出结构余量、剩余任务时间、排队时间和重试退避，在不突破请求大小和总预算的前提下减少请求次数。达到限制 SHALL 报告未处理部分；鉴权失败、限流、格式错误或超时 SHALL 停止相应后续调用并保留此前完整结果。

#### Scenario: 请求预算不足
- **WHEN** 剩余总截止时间不足以安全发送下一批候选
- **THEN** 系统不再发送该批，报告未处理候选和原因，已有完整意见保持可用

#### Scenario: 响应或总预算超限
- **WHEN** 响应超出允许字节数或达到总截止时间
- **THEN** 停止读取或后续调用，保留此前完整处理的结果并标注范围不完整

#### Scenario: 输出预算小于输入预算
- **WHEN** 输入字节允许一批候选，但按结构化输出余量估计无法完整返回该批
- **THEN** 系统缩小批次或停止发送，并记录输出容量不足，而不是把截断 JSON 当作有效意见

## ADDED Requirements

### Requirement: 模型用量可观测
模型结果 SHALL 记录供应商返回的 prompt、completion 和 total usage（若供应商未返回则保持 null），并记录实际请求数、重试数、完成候选数和任务耗时。公开状态、日志和导出 SHALL 不包含凭据或完整供应商原始响应。

#### Scenario: 供应商返回 usage
- **WHEN** 模型响应包含标准 usage 字段
- **THEN** AI 结果和专用导出保存对应 token 用量，并与请求次数关联

#### Scenario: 供应商未返回 usage
- **WHEN** 模型响应没有可验证的 usage 字段
- **THEN** 用量字段保持 null，界面明确显示未知，不根据字符数伪造 token 或成本
